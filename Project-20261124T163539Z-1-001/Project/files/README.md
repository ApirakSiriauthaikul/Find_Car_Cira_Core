# หารถที่จอด

เปิดได้โดยดับเบิลคลิก `index.html` (ไม่ต้องติดตั้งอะไร)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าค้นหารถ |
| `admin.html` | หน้าแอดมิน เพิ่ม/ลบรถ |
| `js/config.js` | **ตั้งค่า:** `API_BASE`, ขนาดลานจอด, การแปลง field จาก API |
| `js/api.js` | เรียก API |
| `js/utils.js` | ฟังก์ชันช่วย และตัวค้นหาป้ายทะเบียน |
| `js/user.js` | การทำงานของหน้าค้นหา แสดงตำแหน่งและรูปถ่าย |
| `js/admin.js` | การทำงานของหน้าแอดมิน |
| `css/style.css` | สไตล์ที่ใช้ร่วมกัน (สี ฟอนต์ หัวเว็บ การ์ด) |
| `css/user.css` | สไตล์เฉพาะหน้าค้นหา |
| `css/admin.css` | สไตล์เฉพาะหน้าแอดมิน |

รูปแบบ API ดูที่หัวไฟล์ `js/config.js`

รูปถ่าย: แอดมินเลือกรูปตอนเพิ่มรถ ระบบย่อเหลือด้านยาว 800px แล้วส่งเป็น data URL ในฟิลด์ `photo` (เซิร์ฟเวอร์ควรรับ body ได้ไม่ต่ำกว่า 300 KB และเก็บคอลัมน์เป็น TEXT)
