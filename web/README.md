# หารถที่จอด (เว็บค้นหารถ)

เว็บนี้อ่านข้อมูลจาก `server.py` (FastAPI) ตัวเดียวกับที่รับข้อมูลจากกล้อง/โมเดลอ่านป้ายทะเบียน

## วิธีรัน
```
pip install fastapi uvicorn
cd Project
python server.py
```
| ที่อยู่ | หน้า |
|---|---|
| http://localhost:8000/web/ | หน้าค้นหารถ (หน้านี้) |
| http://localhost:8000/web/admin.html | หน้าแอดมิน |
| http://localhost:8000/ | แดชบอร์ดเดิมของ server.py |

## ข้อมูลมาจากไหน
`GET /api/slots` → ช่อง `A1-1` = โซน A ชั้น 1 ช่อง 1 (ตั้งใน `js/config.js` ฟังก์ชัน `fromApi`)
ถ้าเพิ่มช่องหรือชั้นใน `SLOTS` ของ `server.py` ให้แก้ `FLOORS`, `ZONES`, `SLOTS` ใน `js/config.js` ให้ตรงกัน

## สิ่งที่เปลี่ยนจากเดิม
- `server.py`: เพิ่มฟิลด์ `parked_at` ใน `/api/slots` และเสิร์ฟโฟลเดอร์ `web/` ที่ `/web`
- เพิ่ม `js/api.js` และ `css/style.css` (ไฟล์ที่ README เดิมอ้างถึงแต่ไม่มีใน zip)
- หน้าค้นหา: ค้นด้วยทะเบียน (3 ตัวขึ้นไป) หรือชื่อจังหวัดได้ แสดงจังหวัด ช่อง และรูปจากกล้อง
- หน้าแอดมิน: "ลบ" = เคลียร์ช่อง (`POST /api/slots/{id}/clear`), "เพิ่มรถ" = ส่งผ่าน `/api/seen`
  **หมายเหตุ:** `server.py` ยังไม่มีระบบรหัสผ่าน หน้าแอดมินจึงเปิดได้โดยไม่ต้องล็อกอิน ถ้าจะใช้จริงควรเพิ่มการตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์
